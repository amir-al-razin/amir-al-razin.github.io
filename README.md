## 🎨 Design Philosophy & Architecture

- **Aesthetic**: Minimalist flat, borderless, shadowless design with tone-on-tone shade layering.
- **Themes**: Dual-mode (Dark / Light) with smooth CSS variables, persistent via `localStorage`, respecting system `prefers-color-scheme`.
- **Performance**: Zero bulky framework overhead - pure semantic HTML5, modern CSS3, and vanilla JavaScript for sub-100ms load times on GitHub Pages.
- **Accessibility**: Keyboard navigable (press `T` to toggle theme), semantic ARIA roles, and high contrast ratios.
